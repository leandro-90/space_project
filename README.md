## 🌌 Sobre o projeto

**Space Tourism** é um site de turismo espacial fictício, construído como projeto colaborativo a partir do desafio *Space Tourism Website* da plataforma **Frontend Mentor**.

A proposta é simples: se você quer ir ao espaço, que seja de verdade, no espaço sideral e não apenas na beirada dele. O site convida o visitante a relaxar e embarcar em uma experiência "fora deste mundo".

> 💡 **Objetivo do time:** praticar HTML, CSS e JavaScript em um projeto real, com design responsivo, navegação entre páginas e trabalho em equipe.

## 💻 Como executar localmente

```bash
# 1. Clone o repositório
git clone https://github.com/leandro-90/space_project.git

# 2. Entre na pasta do projeto
cd space_project

# 3. Abra o index.html no navegador
#    (ou use a extensão Live Server do VS Code)
```

Por ser um projeto estático, não é necessário instalar dependências.
